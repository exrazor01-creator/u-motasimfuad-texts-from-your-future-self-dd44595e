A one-line entry for the "Texts From Your Future Self" bounty: one funny text message from your future self, sent back to the present you. Ten years on, the future self is still living with the same small messes — watering a plant that was never alive, and a camera roll so full of screenshots that nothing can ever be found in it. The program validates the line (at most 200 characters, ASCII, single line) and writes it to `entry.txt`.

## Run it

```sh
python3 main.py
```
